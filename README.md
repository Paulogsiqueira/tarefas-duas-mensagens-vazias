# Lista de Tarefas — Duas Mensagens Vazias

Lista de tarefas que diferencia duas situações de lista vazia: nenhuma tarefa cadastrada e nenhuma tarefa correspondendo aos filtros aplicados. As duas mensagens nunca aparecem juntas, já que cada uma observa uma lista diferente (a lista real e a lista filtrada).

## Funcionalidades

- Cadastro, conclusão, reabertura e remoção de tarefas
- Contador de tarefas pendentes atualizado automaticamente
- Busca por título e filtro por situação, com botão para limpar os filtros
- "Nenhuma tarefa cadastrada" quando a lista real está vazia
- "Nenhuma tarefa corresponde aos filtros" quando há tarefas, mas o filtro escondeu todas

## Rodando o projeto

```bash
npm install
npm run dev
```
